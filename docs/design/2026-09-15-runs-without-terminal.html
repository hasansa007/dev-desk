What changed. Terminals → Runs. A row is a task's run, not a pty; the pane is its event log — text, tool calls, diffs, the plan — read from the agent's protocol stream, never scraped. Chats are gone, both of them; the only place you type is when the run asks (a gate or a question), and that answer goes back over the same channel. Start shows the prepared payload — door, branch, worktree, prompt, gates — and where to run it; the ACP list is what the registry says is installed, the hand-off list is apps Dev Desk launches and then only watches. Continue in is the one escape hatch: the same session in the user's own terminal or app, with the ids carried over. Run project and Survey stay as background rows with a log. New terminal ⌘T becomes Open project in Terminal. SwiftTerm leaves the app.
