# Flows

The things a developer does with the dev family, end to end — one line each. Every door and screen calls a flow
by the name on its line: `dev:arch` for drawing views and sequences, `dev:findings` for the flows a hunt reads,
Dev Desk's Diagrams › Sequence for its list. `also:` lists what other sources have called the same flow, so they
fold into one row instead of three. Add a line for a new flow; add a word to `also:` rather than renaming one.

Every `- ` bullet in this file is a flow, so keep anything that is not one out of a list.
